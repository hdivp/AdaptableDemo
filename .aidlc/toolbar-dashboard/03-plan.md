## Order and reason
Foundation first (T-01 to T-08): the contract, the pure reducer, the shared visual primitives, then the shell itself, proven by T-06 — mounting three unchanged `ToolbarItem`s inside real panels is the moment the seam is shown to work, before any feature-specific styling exists. Each later story (US-02 to US-08) then adds one slice of behaviour on top of that shell, in the order the architecture's Handoff fixes (US-01 through US-08), so a wrong turn in the shell shows up on task six, not on task twenty-five.

## Decisions
- No open sequencing questions: the architecture's Handoff already fixes the build order (US-01 through US-08) and names the foundation pieces every later story reuses, so no ordering choice here would give the user a visibly different "first thing working."

## Handoff
- Start at T-01. Build order is strictly by task id; T-06 is the task that proves the shell approach (three unchanged `ToolbarItem`s rendering inside real panels).
- Seam: `GridPlugin.ToolbarItem` plus the new optional `toolbarTitle`. New feature code goes in `packages/grid-core/src/dashboard/` or a plugin folder, never inline in `GridCore.tsx`.
- AG Grid is imported only inside `packages/grid-core/src`. Do not import it from `apps/demo`.
- Do not touch `react`, `ag-grid-*`, `vite`, or `typescript` versions.
- `LayoutPopup.tsx` is removed in T-26, only after `NameForm.tsx` (T-23) and `LayoutPrompt.tsx` (T-24) exist and `LayoutToolbarItem.tsx` (T-25) no longer references it.
- `gridConfig.ts` is edited twice for different stories (T-08 then T-10) — keep both sets of test switches (`?title=off`, `?titles=off`, then `?tabs=off`) documented in its header comment, alongside the existing `?layouts=off`/`?actions=off`/`?layouts=empty`/`?initialLayout=`.
- Verify each task with `npm run typecheck`; run the full `npm run typecheck && npm run build` before closing out a story's last (verification) task.
- Every "verify" task (T-09, T-11, T-14, T-16, T-18, T-21, T-27, T-29) is manual, against `npm run dev` at `http://localhost:5173`, using the story's AC wording as the check.
- Watch the two noted risks: quick search only matches visible columns (test AC-17 on the Default layout, not one that hides the ticker column), and `?titles=off` panel titles are visually uppercase either way — check AC-06 against DOM text, not a screenshot.
