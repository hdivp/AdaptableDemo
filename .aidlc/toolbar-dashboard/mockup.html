What you see

  • A light header bar: grid name, tabs, quick search, shortcut buttons, settings, collapse.
  • Tabs group toolbars. Click a tab to change the toolbars below it.
  • Each toolbar is a small titled box. The × hides it. The gear brings it back.
  • Collapse leaves only the header bar, so the grid gets more room.

Toolbars, from today's features

  • Layout: pick a layout from a dropdown, then Save, Save as, Edit, Delete.
  • Export: pick CSV or Excel, then Export. Downloads demo-trades.csv.
  • Columns: Auto-size and Fit to width.
  • Quick search: new. Filters rows as you type.

Stays the same

  • Features are still GridPlugins in config.plugins.
  • The demo still imports nothing from AG Grid.
  • AG Grid 32 and React 18. No version bumps.
